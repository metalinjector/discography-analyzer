# Discography Analyzer

Настольная программа на Python для безопасного анализа локальной музыкальной
коллекции. Обычный анализ работает только на чтение: программа не удаляет,
не перемещает и не переименовывает исходную музыку. Изменение тегов возможно
только после отдельного предпросмотра и явного подтверждения пользователя.

## Возможности

- поиск MP3, FLAC, M4A и APE в выбранной папке и подпапках;
- продолжение анализа при единичных недоступных файлах с указанием количества
  пропусков в итоговом статусе;
- стабильный алфавитный порядок обхода файлов и папок между запусками;
- чтение основных, технических и пользовательских тегов через Mutagen;
- показ встроенных обложек;
- строгий поиск дубликатов по полностью одинаковому названию, точно одинаковой
  длительности без допуска и хотя бы одному общему артисту;
- непосредственные связи между файлами внутри общей группы дубликатов без
  ложного утверждения, что каждый файл совпадает с каждым;
- распознавание `feat.`, `ft.`, `&`, запятых и других разделителей артистов;
- связь ремикса, live-версии и другой вариации только с одним однозначным
  исходным файлом;
- раскрываемые группы `[+]` для дубликатов и вариаций: внутри всегда видны
  все связанные файлы, включая исходник вариации;
- статусы «Уникальный», «Дубликат», «Вариация» и «Конфликт»;
- собранные слева вкладки, плавный отложенный фильтр, сортировка,
  множественное выделение и копирование;
- ручное изменение ширины всех столбцов без автоматического возврата и кнопка
  автоподгонки по заголовкам и содержимому ячеек;
- обычный и древовидный режим просмотра структуры папок, кнопки быстрого
  разворачивания и сворачивания всего дерева;
- проверка пропущенных треков по `Track #`: как по итоговому значению `1/10`,
  так и по разрывам последовательности `1, 2, 3, 4, 6`;
- строгая бело-оранжевая тема с тёплыми и металлическими оттенками,
  контрастный тёмный вариант и сохранение настроек;
- автоматический аудит метаданных с отдельной вкладкой: обязательные теги,
  Artist/Album Artist, нумерация, согласованность альбома, читаемость и
  встроенные обложки;
- безопасная нормализация разделителей исполнителей и пробелов только после
  предпросмотра; исходный файл заменяется лишь после повторного чтения
  записанных тегов, резервная копия включена по умолчанию;
- настраиваемый XLSX-отчёт с пятью видами листов, включая
  «Аудит метаданных», строками высотой
  `17,25`, оранжевыми заголовками и зелёными, голубыми и коралловыми
  смысловыми акцентами;
- атомарное сохранение XLSX: при ошибке записи ранее существовавший отчёт
  не повреждается;
- копирование уникальной подборки единым пронумерованным списком либо с
  сохранением исходной структуры папок;
- необязательная группировка порядка копирования по исполнителям: исполнители
  по алфавиту, релизы каждого исполнителя от новых дат к старым;
- отдельная необязательная папка «Не скопировано» для повторов и конфликтов,
  исключённых из основной подборки.

## Установка

Нужен Python 3.10 или новее. В каталоге проекта выполните:

```bash
python -m pip install -r requirements.txt
```

На некоторых Linux-системах Tkinter устанавливается отдельно, например:

```bash
sudo apt install python3-tk
```

## Запуск

Windows:

```powershell
py app.py
```

Linux и macOS:

```bash
python3 app.py
```

Либо после установки проекта:

```bash
python -m pip install .
discography-analyzer
```

## Основной сценарий

1. Нажмите «Выбрать...» и укажите корневую папку коллекции.
2. Выберите форматы, режим подпапок и использование тегов.
   Для контроля полноты альбомов оставьте включённым флажок
   «Проверять пропуски номеров треков».
3. Нажмите «Начать анализ» или `F5`.
4. Используйте вкладки, фильтр и сортировку.
   Нажмите `[+]` у дубликата или вариации, чтобы раскрыть связанные файлы.
   Во вкладке «По папкам» можно включить «Древовидный вид», а затем одной
   кнопкой развернуть или свернуть всю структуру.
5. Выберите строку для полной информации и обложки.
6. Для связанной вариации используйте контекстное действие
   «Показать исходный трек».
7. Нажмите «Копировать уникальные...», чтобы сформировать подборку без
   повторяющихся дублей и вариаций.
8. Откройте вкладку «Аудит» для просмотра ошибок, предупреждений и
   рекомендаций. Для однозначных механических правок доступна кнопка
   «Исправить замечания...».
9. Нажмите «Экспорт в XLSX» для настройки и сохранения отчёта.

Горячие клавиши: `Ctrl+O` — выбрать папку, `Ctrl+E` — экспорт, `F5` — анализ.

## Правила классификации

Дубликат подтверждается только при выполнении всех условий:

1. названия полностью идентичны с учётом регистра и знаков;
2. точная длительность полностью идентична, без допуска;
3. совпадает хотя бы один артист.

Из-за этого `Artist A feat. Guest` и `Artist A` считаются имеющими общего
артиста. Известная разная длительность всегда означает разные треки.
Отсутствующие обязательные данные создают конфликт для ручной проверки.

Обозначение `Remix`, `Live` или другое само по себе не назначает статус
вариации. Требуется ровно один файл без обозначения версии, полностью
совпадающее базовое название и общий артист. При отсутствии исходника или при
нескольких возможных исходниках файл остаётся самостоятельным.

## Проверка комплектности альбомов

Проверка выполняется внутри каждой папки отдельно для каждого значения `Album`
и номера диска:

- при тегах `1/10`, `2/10` и т. д. программа проверяет весь диапазон до 10;
- при простых номерах без общего количества программа ищет внутренние разрывы;
- `TRACKTOTAL`, `TOTALTRACKS`, `DISCTOTAL` и MP4-атомы `trkn`/`disk`
  также учитываются;
- многодисковые издания проверяются по дискам раздельно;
- файлы без `Track #` и противоречивые итоговые значения помечаются отдельно.

Предупреждения видны в колонке «Проверка комплекта», карточке файла,
древовидном представлении, итоговой статистике и XLSX-отчёте.

## Аудит метаданных

После классификации программа автоматически проверяет каждый файл и
согласованность треков внутри папки/альбома:

- отсутствие `Title`, `Artist`, `Album`, `Album Artist`, даты и встроенной
  обложки;
- ошибки чтения аудио, тегов и повреждённые встроенные изображения;
- разделители и пробелы между исполнителями, например `Riana;Moby` →
  `Riana, Moby`;
- несогласованность `Artist` и `Album Artist`. Дополнительный приглашённый
  исполнитель считается рекомендацией для проверки, а не безусловной ошибкой;
- некорректные, отсутствующие и повторяющиеся номера треков и дисков;
- единичные отличия `Album`, `Album Artist`, даты и обложки от большинства
  треков того же альбома.

Замечания сгруппированы по файлам и раскрываются значком `[+]`. Ошибки,
предупреждения и рекомендации выделены разными контрастными цветами.
Автоматически исправляются только однозначные преобразования разделителей и
пробелов, выбранные пользователем в окне предпросмотра. Остальные предложения
остаются информационными и не меняют теги.

## Копирование уникальной подборки

После анализа кнопка «Копировать уникальные...» открывает отдельное окно:

- «Единым списком» помещает файлы непосредственно в выбранную папку и
  присваивает им имена вида
  `01 Исполнитель - Альбом (Год) - 05-Название.flac`;
- «С сохранением структуры папок» воссоздаёт относительные пути исходной
  коллекции;
- «Разобрать по исполнителям» сначала группирует исполнителей по алфавиту,
  затем располагает релизы каждого исполнителя от новых дат к старым;
- флажок «Также создать папку „Не скопировано“» сохраняет исключённые файлы
  тем же выбранным способом.

Отбор выполняется от старых дат к новым: сначала используется год из тега,
а при его отсутствии — дата файла. Уникальные треки сохраняются. Из
подтверждённых прямых дублей остаётся самый ранний доступный представитель.
Одинаковая вариация повторно не копируется, только если совпали её базовое
название, обозначение версии, точная длительность и хотя бы один артист.
Неполные данные не используются для опасного предположения об одинаковости:
такие вариации сохраняются, а файлы со статусом «Конфликт» относятся к
исключённым. Существующие файлы в папке назначения не перезаписываются.
Группировка по исполнителям меняет только порядок и нумерацию копирования,
но не правило выбора самого раннего представителя дубля.

## Тесты

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют строгую классификацию, разбор вариаций и артистов, сохранение
настроек, структуру XLSX-отчёта и оба режима безопасного копирования.
